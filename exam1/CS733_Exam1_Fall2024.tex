Prove (i.e., using the definitions), or disprove (i.e., using contradiction or with a counterexample).

\begin{itemize}
    \item[(a)] $f(n) = O(g(n))$ implies that $g(n) = O(f(n)).$ \\
        \textbf{Answer: }We aim to disprove the claim that if \( f(n) = O(g(n)) \), then \( g(n) = O(f(n)) \). \\
        The definition of Big-O notation is as follows:
        \[f(n) = O(g(n)) \iff \exists \, c > 0, n_0 > 0 \text{ such that } 0 \leq f(n) \leq c \cdot g(n) \text{ for all } n \geq n_0.\]
        To disprove the statement, we will provide a \textbf{counterexample}.
        \begin{proof} (By counterexample.) Let us consider the following functions:
            \[f(n) = n \quad \text{and} \quad g(n) = n^2.\]
            First, we check if \( f(n) = O(g(n)) \). By the definition of Big-O, we need to show that there exist constants \( c > 0 \) and \( n_0 \) such that: \[n \leq c \cdot n^2 \quad \text{for all} \quad n \geq n_0.\] Dividing both sides by \( n \) (assuming \( n > 0 \)): \[1 \leq c \cdot n.\]
            This inequality is true for \( n \geq 1 \) if we choose \( c = 1 \). Thus, \( f(n) = n \) is indeed \( O(n^2) \).
            Now, we check if \( g(n) = O(f(n)) \). We need to check if there exist constants \( c' > 0 \) and \( n_0' \) such that: \[n^2 \leq c' \cdot n \quad \text{for all} \quad n \geq n_0'.\] Dividing both sides by \( n \) (assuming \( n > 0 \)): \[n \leq c',\] which is clearly false for large \( n \) because \( n \) grows without bound. Therefore, \( g(n) = n^2 \) is \emph{not} \( O(n) \).
        \end{proof}
        \newpage
        
    \item[(b)] If $f(n) = O(g(n))$ and $g(n) = O(h(n))$ then $f(n) = O(h(n)).$ \\
        \textbf{Answer: }We aim to prove this statement using the definition of Big-O notation. \\
        By definition, \( f(n) = O(g(n)) \) means that there exist some constants \( c_1 > 0 \) and \( n_1 > 0 \) such that:
        \[ |f(n)| \leq c_1 \cdot |g(n)| \quad \text{for all} \quad n \geq n_1. \]
        Similarly, \( g(n) = O(h(n)) \) means that there exist constants \( c_2 > 0 \) and \( n_2 > 0 \) such that:
        \[ |g(n)| \leq c_2 \cdot |h(n)| \quad \text{for all} \quad n \geq n_2. \]
        Now, we need to show that \( f(n) = O(h(n)) \), meaning there exist constants \( c_3 > 0 \) and \( n_3 > 0 \) such that:
        \[ |f(n)| \leq c_3 \cdot |h(n)| \quad \text{for all} \quad n \geq n_3. \]
        \begin{proof}
            Since \( |f(n)| \leq c_1 \cdot |g(n)| \) for \( n \geq n_1 \), and \( |g(n)| \leq c_2 \cdot |h(n)| \) for \( n \geq n_2 \), we can substitute the second inequality into the first:
            \[ |f(n)| \leq c_1 \cdot |g(n)| \leq c_1 \cdot c_2 \cdot |h(n)|. \]
            Thus, we have:
            \[ |f(n)| \leq c_3 \cdot |h(n)| \quad \text{where} \quad c_3 = c_1 \cdot c_2. \]
            Now, let \( n_3 = \max(n_1, n_2) \), ensuring both conditions hold for all \( n \geq n_3 \). Therefore, we have shown that there exist constants \( c_3 = c_1 \cdot c_2 \) and \( n_3 = \max(n_1, n_2) \) such that:
            \[ |f(n)| \leq c_3 \cdot |h(n)| \quad \text{for all} \quad n \geq n_3. \]
            Hence, \( f(n) = O(h(n)) \).
        \end{proof}
        \newpage
    
    \item[(c)] $f(n)+g(n) = \Theta(\min(f(n), g(n))).$ \\
        \textbf{Answer: }We disprove the statement by providing a counterexample.
        \begin{proof} (By counterexample.) Let \( f(n) = n \) and \( g(n) = n^2 \).
            In this case, the sum of the two functions is:
            \[ f(n) + g(n) = n + n^2. \]
            The minimum of the two functions is:
            \[ \min(f(n), g(n)) = \min(n, n^2) = n. \]
            Now, we check if \( f(n) + g(n) = \Theta(\min(f(n), g(n))) \). This would mean there exist constants \( c_1, c_2 > 0 \) and an integer \( n_0 \) such that for all \( n \geq n_0 \):
            \[ c_1 \cdot n \leq n + n^2 \leq c_2 \cdot n. \]

            \textbf{Upper bound:} We first check if the upper bound \( n + n^2 \leq c_2 \cdot n \) holds for large \( n \). For large \( n \), \( n^2 \) dominates \( n \), so \( n + n^2 \) grows like \( n^2 \), which cannot be bounded by \( c_2 \cdot n \) for any constant \( c_2 \). Therefore, the upper bound fails.

            \textbf{Lower bound:} The lower bound \( n + n^2 \geq c_1 \cdot n \) holds for sufficiently large \( n \), since \( n^2 \) is positive and dominates \( n \), ensuring that \( n + n^2 \geq c_1 \cdot n \).

            Since the upper bound fails, we conclude that \( f(n) + g(n) \neq \Theta(\min(f(n), g(n))) \). Therefore, the original statement is false.
        \end{proof}
        \newpage

    \item[(d)] $f(n)= O(g(n))$ implies $2^{f(n)} = O(2^{g(n)}).$ \\
        \textbf{Answer:} We disprove the statement by providing a counterexample.
        \begin{proof} (By counterexample.) Let \( f(n) = n \) and \( g(n) = \frac{n}{2} \).
        \begin{itemize}
            \item[(1.)] Check if \( f(n) = O(g(n)) \). \\
            We need to show that there exist constants \( c > 0 \) and \( n_0 \geq 0 \) such that for all \( n \geq n_0 \),
            \[ f(n) \leq c \cdot g(n). \] 
            Substituting \( f(n) = n \) and \( g(n) = \frac{n}{2} \), we get:
            \[ n \leq c \cdot \frac{n}{2}, \]
            which simplifies to:
            \[ 2 \leq c. \]
            This holds for \( c = 2 \), so \( f(n) = O(g(n)) \).
            \item[(2.)] Check if \( 2^{f(n)} = O(2^{g(n)}) \). \\
            We need to check whether there exist constants \( c' > 0 \) and \( n_0' \geq 0 \) such that for all \( n \geq n_0' \),
            \[ 2^{f(n)} \leq c' \cdot 2^{g(n)}. \]
            Substituting \( f(n) = n \) and \( g(n) = \frac{n}{2} \), we get:
            \[ 2^n \leq c' \cdot 2^{n/2}. \]
            Dividing both sides by \( 2^{n/2} \), we get:
            \[ 2^{n/2} \leq c'. \]
            As \( n \to \infty \), \( 2^{n/2} \) grows without bound, which means no constant \( c' \) can satisfy this inequality for large \( n \). Therefore, \( 2^n \neq O(2^{n/2}) \).
        \end{itemize}
        Therefore, the statement $f(n)= O(g(n))$ implies $2^{f(n)} = O(2^{g(n)})$ is false, as shown by the counterexample \( f(n) = n \) and \( g(n) = \frac{n}{2} \).
        \end{proof}
        \newpage
    
    \item[(e)] $n = O(n^{0.9999999} \log (n))$. \\
        \textbf{Answer: } The statement \( n = O(n^{0.9999999} \log n) \) is false.
        \begin{proof}
            Suppose, for contradiction, that \( n = O(n^{0.9999999} \log n) \). This would mean that there exist constants \( c > 0 \) and \( n_0 \geq 0 \) such that for all \( n \geq n_0 \),
            \[ n \leq c \cdot n^{0.9999999} \log n. \]
            Dividing both sides by \( n^{0.9999999} \), we get:
            \[ n^{0.0000001} \leq c \cdot \log n. \]

            Then, consider the growth rates of \( n^{0.0000001} \) and \( \log n \) as \( n \to \infty \):
            \begin{itemize}
                \item[] \( n^{0.0000001} \) grows asymptotically faster than \( \log n \), since even a small power of \( n \) grows faster than the logarithmic function.
            \end{itemize}
            Thus, for sufficiently large \( n \), \( n^{0.0000001} \) exceeds \( c \cdot \log n \), which contradicts the assumption that \( n \leq c \cdot n^{0.9999999} \log n \). 
            
            Therefore, the assumption that \( n = O(n^{0.9999999} \log n) \) is false.
        \end{proof}
        \newpage
\end{itemize}

\vs\

Let $G$ be a connected graph with $n$ vertices.

\begin{itemize}
    \item[(a)] Prove by induction that $G$ contains a spanning tree.
    \begin{theorem}
        Let \( G \) be a connected graph with \( n \) vertices. Then, \( G \) contains a spanning tree.
    \end{theorem}
    \begin{proof} We will prove this statement by induction on the number of vertices \( n \) in the connected graph \( G \).
    \begin{itemize}
        \item[] \textbf{Base Case:} \( n = 1 \) \\
        If \( G \) has only one vertex and no edges, it trivially contains a spanning tree. In this case, the single vertex itself is a spanning tree with no edges, since there are no other vertices to connect. Hence, the graph contains a spanning tree.
        \item[] \textbf{Inductive hypothesis:} Assume that for any connected graph with \( k \) vertices (where \( k \geq 1 \)), there exists a spanning tree. This means that for any connected graph with \( k \) vertices, we can find a subgraph that includes all the vertices of \( G \) and is a tree (i.e., connected and acyclic).
        \item[] \textbf{Inductive step:} Now, we consider a connected graph \( G \) with \( n = k+1 \) vertices. We need to show that \( G \) contains a spanning tree. 
        \begin{itemize}
            \item[1.] \textbf{Remove a vertex and edge connections:}
            \begin{itemize}
                \item Select any vertex \( v \) in \( G \) and remove it from the graph, along with all edges connected to \( v \).
                \item The resulting graph \( G' \) has \( k \) vertices and remains connected (since removing a single vertex from a connected graph cannot disconnect it as long as there are still connections between other vertices).
            \end{itemize}
            \item[2.] \textbf{Apply the inductive hypothesis:}
            \begin{itemize}
                \item By the inductive hypothesis, the smaller graph \( G' \), with \( k \) vertices, contains a spanning tree \( T' \) (i.e., a connected, acyclic subgraph that spans all \( k \) vertices of \( G' \)).
            \end{itemize}
            \item[3.] \textbf{Reconnect the removed vertex: }
            \begin{itemize}
                \item Now, add back the vertex \( v \) and one of its edges to any vertex in the spanning tree \( T' \). Since \( G \) is connected, such an edge must exist.
                \item By adding this edge, we ensure that the vertex \( v \) is now connected to the spanning tree \( T' \), and since we only added one edge, the resulting graph remains acyclic.
            \end{itemize}
        \end{itemize}
        Thus, the graph \( G \) with \( n = k+1 \) vertices contains a spanning tree.
        \item[] \textbf{Conclusion:} By induction, we have shown that every connected graph with \( n \) vertices contains a spanning tree. 
    \end{itemize}
    \end{proof}
    \newpage
    \item[(b)] Prove that if $G$ has $n$ or more edges, then $G$ contains a cycle. (Hint: Use Part (a) and a tree of $n$ vertices has $n-1$ edges). 
    \begin{theorem}
        Let \( G \) be a connected graph with \( n \) vertices and \( m \geq n \) edges. Then, \( G \) contains a cycle.
    \end{theorem}
    \begin{proof} We will use the result from Part (a), which states that every connected graph with \( n \) vertices contains a spanning tree.
    \begin{itemize}
        \item[Step 1:] \textbf{Existence of a spanning tree (from Part (a)).} \\
        By the result from Part (a), we know that \( G \), being a connected graph with \( n \) vertices, contains a spanning tree \( T \). A spanning tree is a connected, acyclic subgraph that includes all \( n \) vertices of \( G \) and has exactly \( n-1 \) edges (as every spanning tree of \( n \) vertices does).
        \item[Step 2:] \textbf{Analyze the number of edges in \( G \).} \\
        Since \( G \) is given to have \( m \geq n \) edges, it must have more edges than the spanning tree \( T \), which has exactly \( n-1 \) edges.
        \item[Step 3:] \textbf{Adding extra edges creates a cycle.} \\
        The spanning tree \( T \) already spans all the vertices of \( G \), meaning it connects all \( n \) vertices without any cycles. 
        Now, consider any extra edges in \( G \) (there are at least one because \( m \geq n \)). Each extra edge must connect two vertices that are already connected in the spanning tree \( T \) because the tree spans all vertices. \\
        
        Adding such an extra edge creates a cycle, as it introduces an additional path between two vertices that already have a unique path in the spanning tree.
    \end{itemize}
    Since adding any edge to a spanning tree creates a cycle, \( G \), which has \( n \) or more edges, must contain at least one cycle.
    \end{proof}
\end{itemize}

Let $G = (V,E,W)$ be a weighted connected (undirected) graph, where $V$ is the set of vertices, $E$ is the set of edges, $w_e \in W$ for each $e \in E$ is a nonnegative weight of the edge $e$. A spanning tree is defined as usual, namely $T = (V, T_E)$ where $T_E$ is a subset of  $E$ and $T$ is a tree. The width of a spanning tree $T$ is max $\{w_e | e \in T_E \}$.  Thus it is the most “expensive” edge in the tree. $T$ is a Minimum width spanning tree of $G$ if it is a spanning tree and achieves the minimum width among all spanning trees of $G.$ 
\begin{itemize} 
    \item[(a)] Prove that any minimum spanning tree of $G$ is also a minimum width spanning tree of $G$. (Hint: You may use proof by contradiction.)
    \begin{proof}
        To prove that any Minimum Spanning Tree (MST) of $G$ is also a Minimum Width Spanning Tree (MWST), we proceed by contradiction.
        \begin{itemize}
            \item Suppose $T$ is a minimum spanning tree of $G$, but $T$ is not a Minimum Width Spanning Tree.
            \item This means there exists another spanning tree $T'$ with $\max \{w_e \mid e \in T'_E\} < \max \{w_e \mid e \in T_E\}$, implying that the maximum edge weight in $T'$ is smaller than the maximum edge weight in $T$.
            \item However, because $T$ is an MST, it has the smallest possible total weight among all spanning trees in $G$. The presence of a spanning tree $T'$ with a smaller maximum edge weight suggests that $T$ could be modified to reduce its maximum edge weight without increasing its total weight.
            \item Specifically, we could replace an edge in $T$ with an edge from $T'$ (if needed) to obtain a tree with the same or lower total weight and a smaller maximum edge weight, which would contradict the assumption that $T$ is an MST.
            \item Thus, by contradiction, any MST of $G$ must also be a Minimum Width Spanning Tree.
        \end{itemize}
    \end{proof}
    
    \item[(b)] Show with an example that even if the weights of $G = (V,E,W)$ are all distinct, there could be more than one minimum width spanning tree.
    \begin{proof}

        \begin{itemize}
            \item[] Edge $A - B$ with weight 1
            \item[] Edge $A - C$ with weight 2
            \item[] Edge $B - D$ with weight 4
            \item[] Edge $C - D$ with weight 3
            \item[] Edge $B - C$ with weight 5
        \end{itemize}

        \begin{itemize}
            \item[] \textbf{Tree 1:} $\{A - B, A - C, B - D\}$ with a maximum edge weight of 4.
            \item[] \textbf{Tree 2:} $\{A - B, B - D, C - D\}$ with a maximum edge weight of 4.
        \end{itemize}

    \end{proof}

Consider the collection of all undirected graphs with 10 nodes and 6 edges. Let M and m, respectively, be the maximum and minimum number of connected components in any graph in the collection. If a graph has no selfloops and there is at most one edge between any pair of nodes, which of the following is true? 

\begin{itemize}
    \item[(A)] M = 10, m = 10
    \item[(B)] M = 10, m = 1
    \item[(C)] M = 7, m = 4
    \item[(D)] M = 6, m = 4
    \item[(E)] M = 6, m = 3
\end{itemize}

Justify your selection by ruling out the other choices. Show two graphs that satisfy $M$ and $m$. \\

\noindent \textbf{Answer: }We analyze the maximum and minimum possible number of connected components in a graph with 10 nodes and 6 edges. We consider two cases: 
\begin{itemize}
    \item maximizing the number of connected components, and
    \item minimizing the number of connected components, using only 6 edges.
\end{itemize}

\begin{itemize}
    \item[(1)] {\bf Maximum Number of Connected Components (M):}
    
    To maximize the number of connected components, we aim to keep as many nodes isolated as possible. With 10 nodes, we add edges incrementally, ensuring that each edge connects a new pair of nodes to avoid reducing the number of components unnecessarily.

    - Adding one edge creates a connected component of 2 nodes, leaving 8 isolated nodes, resulting in 9 connected components.
    - Adding two edges, each connecting a different pair of nodes, gives two 2-node components and 6 isolated nodes, resulting in 8 connected components.
    - Adding three edges with each edge connecting a different pair of nodes results in three 2-node components and 4 isolated nodes, which gives 7 connected components.
    - Adding four edges with each edge connecting a different pair of nodes results in four 2-node components and 2 isolated nodes, which gives 6 connected components.

    \noindent Thus, the maximum number of connected components achievable with 6 edges is \( M = 6 \).

    \item[(2)] {\bf Minimum Number of Connected Components (m):}

    To minimize the number of connected components, we want to connect as many nodes as possible into a single component while using only 6 edges.

    - Using a tree structure, we can connect up to 7 nodes with 6 edges (since a tree with \( n \) nodes requires \( n-1 \) edges).
    - This configuration leaves the remaining 3 nodes isolated.

    \noindent Therefore, we have one connected component of 7 nodes and 3 isolated nodes, resulting in a minimum of 4 connected components. Hence, \( m = 4 \).
\end{itemize}

\noindent {\bf Conclusion:} The correct answer is:

\[
\boxed{(D) \, M = 6, m = 4}
\]

\noindent To rule out the other options:

\begin{itemize}
    \item[(A)] \( M = 10, m = 10 \): This is impossible because, with 6 edges, we cannot have all nodes isolated.
    \item[(B)] \( M = 10, m = 1 \): With only 6 edges, it is impossible to connect all 10 nodes in a single component.
    \item[(C)] \( M = 7, m = 4 \): \( M = 7 \) is not achievable, as shown by the analysis above.
    \item[(E)] \( M = 6, m = 3 \): \( m = 3 \) cannot be achieved with only 6 edges, as connecting a large component with 10 nodes would require more edges.
\end{itemize}
